당신은 임원 보고용 PPT 삽화 디자이너다. 첨부한 참고 슬라이드(제조 Physical AI 6단계 파이프라인)의 박스 안 삽화 톤(신경망 아이콘, DB 실린더, 플랫한 파란 계열)과 어울리는 삽화 15종을 만들어 ./out/ 에 PNG 로 저장하라.

방법: 이미지 생성 도구(image generation tool)가 있으면 그것을 우선 사용하라. 없으면 SVG 를 코드로 직접 작성한 뒤 rsvg-convert, cairosvg, 또는 google-chrome --headless 로 PNG 변환하라. 어떤 방법을 썼는지, 이미지 생성 도구가 있었는지 없었는지를 ./out/METHOD.md 에 2~3줄로 적어라.

규격: 투명 배경(불가하면 흰 배경), 한 변 600px 이상, 정사각형. 파일명은 아래 번호_이름.png.
스타일: 플랫 벡터, 얇은 선, 텍스트·글자 절대 넣지 말 것. 팔레트 = 남색 #203768, 파랑 #0E5DB7, 연파랑 #A6CAEC, 연회색 #F3F6FC. 신경망 3종만 각각 보라(#8E44AD 계열)·초록(#27AE60 계열)·파랑(#0E5DB7) 사용.

목록:
01_designer_chat — 설계자(사람 실루엣)가 AI 와 대화하는 말풍선 2개
02_upload_docs — 문서 파일과 소스코드 파일이 위로 업로드되는 모습
03_knowledge_db — DB 실린더 위에 지식 카드 3장이 쌓이는 모습
04_refine_funnel — 흩어진 원시 데이터 점들이 깔때기를 지나 정돈된 카드가 되는 모습
05_tokens — 문장 줄이 작은 블록(토큰) 열로 바뀌는 모습
06_neural_generic — 범용 신경망(보라)
07_neural_domain — 도메인 특화 신경망(초록)
08_neural_advanced — 고도화 신경망(파랑, 노드 더 촘촘)
09_feedback — 엄지 위·아래 평가 버튼과 별점
10_distill_quantize — 큰 신경망이 작은 신경망으로 압축되는 모습(화살표 포함)
11_gpu_server — 사내 GPU 서버 랙
12_web_ide — 웹 브라우저 창과 코드 편집기 창
13_doc_gen — 설계 문서가 생성되는 모습(문서+톱니바퀴)
14_code_gen — 코드가 생성되는 편집기 창(</> 기호는 허용)
15_static_check — 방패 위 체크 표시(정적 검증)

완료 후 ./out/ 에 15개 PNG 와 METHOD.md 가 있는지 ls 로 확인하고 끝내라.
